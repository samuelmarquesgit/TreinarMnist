🐛 Bugs & Riscos

Achados com impacto direto no comportamento esperado da plataforma, ordenados por severidade.

#1 Guardrail de overconfidence nunca dispara para modelos sklearn Crítico
Arquivoguardrails/validador_falsa_certeza.py · linha 38
ImpactoO experimento OOD central da rubrica (classe masking) é silenciosamente ineficaz
Causa alerta_overconfidence só é True quando classe_prevista not in classes_conhecidas. Mas modelos sklearn sempre preveem dentro do conjunto de classes de treino (0–9 exceto 4 e 7). argmax(prob) sempre cai em uma das classes conhecidas, logo o alerta nunca dispara.
CorreçãoUsar entropia como critério primário: alerta quando confianca_maxima ≥ limiar AND entropia < limiar_entropia_baixa, independente da classe prevista.
alerta_overconfidence = (
    confianca_maxima >= self.limiar_alerta_certeza and
    entropia < self.limiar_entropia_baixa  # ← critério correto para OOD
)
#2 4 modelos fantasma no painel de Benchmarks causam métricas zeradas silenciosas Crítico
Arquivosrc/frontend/painel_benchmarks.py · linha 49
ModelosRegressaoLinear, AgrupamentoKMeans, PerceptronManual, RedeNeuralMLP
ImpactoQuando o usuário seleciona esses modelos, a fábrica lança ValueError, capturado silenciosamente, inserindo acurácia=0 na tabela comparativa. Parece que o modelo "rodou" mas falhou.
CorreçãoSincronizar MODELOS_DISPONIVEIS com FabricaModelos._REGISTRO_MODELOS.keys() ou implementar os modelos faltantes.
#3 AnalisadorRobustezOOD.relatorio_overconfidence() sempre lança TypeError para sklearn Crítico
Arquivossrc/robustez_ood.py · src/modelos/fabrica_modelos.py
CausaModeloSklearn não implementa prever_probabilidades(). O método verifica hasattr(modelo, "prever_probabilidades") e lança TypeError antes de qualquer cálculo.
CorreçãoAdicionar prever_probabilidades() a ModeloAbstratoIA e implementar em ModeloSklearn via predict_proba(). Usar probability=True no SVC.
def prever_probabilidades(self, X_teste: Any) -> np.ndarray:
    if hasattr(self.modelo, "predict_proba"):
        return self.modelo.predict_proba(X_teste)
    raise NotImplementedError(f"{self.nome_log} não suporta predict_proba")
#4 ModeloViT.prever() retorna valores aleatórios sem seed fixo Crítico
Arquivosrc/modelos/vision_transformer.py · linha 30
ImpactoResultados não reproduzíveis; métricas mudam a cada chamada; usuário não percebe que é mock.
CorreçãoDocumentar claramente como SKELETON — aguardando PyTorch e usar np.random.default_rng(42) para resultados determinísticos enquanto o ViT real não é implementado.
#5 Pipeline de visão computacional incompleto — não centraliza imagem em 28×28 Crítico
Arquivosrc/visao_computacional.py
ImpactoA rubrica exige: grayscale → inversão → BBox crop → resize 20×20 → pad/centralizar 28×28. A implementação atual só faz grayscale → resize direto para 28×28, perdendo o alinhamento com o MNIST.
CorreçãoImplementar BBox crop (bounding box do dígito) com OpenCV contornos, resize 20×20, pad para 28×28 com bordas pretas.
#6 Fuga de arquivo temporário no Laboratório de Visão Alto
Arquivosrc/frontend/painel_laboratorio_visao.py
CausaUso de NamedTemporaryFile sem delete=True e sem gerenciador de contexto explícito — arquivos temporários acumulam no disco.
CorreçãoUsar with tempfile.NamedTemporaryFile(delete=True, suffix=".png") as f: ou trabalhar diretamente com io.BytesIO sem gravar em disco.
#7 assert em produção pode ser desativado com -O Médio
Arquivosrc/pre_processamento.py · linha 44
Causaassert np.min(X_treino_norm) >= -1e-7 ... — com python -O, assert é ignorado e a validação de leakage silencia.
CorreçãoSubstituir por if not (condição): raise ValueError(...)
#8 ValidadorVazamentoDados não é determinístico Médio
Arquivoguardrails/validador_vazamento_dados.py · linha 24
Causanp.random.choice() sem seed — testes podem flutuar entre execuções; O(n·m) para n=70k e m=1k é lento.
CorreçãoUsar rng = np.random.default_rng(42) e substituir por busca vetorial com cdist ou KDTree para eficiência.

🔍 Code Smells & Dívida Técnica

Problemas de qualidade sem impacto imediato, mas que aumentam o custo de manutenção.

logging.basicConfig() em nível de módulo
Configura o logging global ao importar o módulo, sobrescrevendo configurações do host (Streamlit, pytest).

print() em vez de logger.info()
Mensagens de download e cache aparecem no stdout sem controle de nível de log.
carregador_dados.py

Método essencial para OOD, RAG e Laboratory Panel não está no contrato abstrato, quebrando o padrão Strategy.
base_modelo.py · fabrica_modelos.py · robustez_ood.py

aplicar_estilos() chamada no início de cada painel além de em app.py — CSS injetado múltiplas vezes.
painel_benchmarks.py · outros painéis
Hiperparâmetros hardcoded na fábrica
n_estimators=50, max_iter=300, etc. embutidos no código — difícil tunear sem alterar a fábrica.
fabrica_modelos.py
MongoDB write-only sem método de leitura
ConexaoMongoDB só tem salvar_artefato() — o painel de bancos não consegue listar o que foi salvo.
conexao_mongodb.py · painel_bancos_dados.py
Tabela Experimentos com schema mínimo
Sem colunas para precisao, recall, f1, hiperparametros — persistência de benchmark incompleta.
conexao_postgres.py
os.system() para lançar processos filhos
Má prática — bloqueia o processo pai, não captura erros, não suporta SIGTERM adequado.
main.py
Agent stubs sem implementação real

Servidor MCP e RAG ausentes
src/mcp/ e src/rag/ são diretórios vazios. mcp_servidor.py referenciado no main.py não existe.
src/mcp/ · src/rag/ · main.py
Sem conftest.py com fixtures compartilhadas
Cada teste recria dados sintéticos independentemente — alto custo de manutenção se a interface mudar.
tests/ (todos)
SVC sem probability=True na fábrica

🏛️ Melhorias Arquiteturais (Mercado 2024-2025)

Padrões adotados em plataformas de ML de produção que elevariam este projeto ao nível enterprise.

📐
Pydantic v2 para schemas de métricas
Substituir dicts por BaseModel do Pydantic. Validação automática, serialização JSON, documentação auto-gerada. Especialmente útil no retorno de calcular_metricas().
Pydantic v2 · FastAPI pattern
⚙️
Configuração externalizada (YAML + Pydantic Settings)
Hiperparâmetros dos modelos em config/modelos.yaml, carregados via pydantic-settings. Permite variação de experimentos sem alterar código-fonte.
12-Factor App · MLflow-style
🔬
MLflow ou DVC para rastreabilidade de experimentos
Substituir (ou complementar) o Postgres manual por mlflow.log_metric(). Oferece UI de comparação de runs, artefatos versionados e registry de modelos sem custo adicional.
MLflow 2.x · Experiment Tracking
🛡️
typing.Protocol para Guardrails
Definir Protocol com método avaliar() em vez de ABC. Permite duck typing — qualquer classe com avaliar() funciona sem herança. Mais flexível e testável.
Structural Subtyping · PEP 544
🚀
FastAPI como backend alternativo ao MCP
Expor a FachadaPipelineIA via REST/WebSocket com FastAPI. Permite desacoplar o frontend Streamlit do processamento pesado e habilitar acesso multi-cliente.
FastAPI · async · OpenAPI
🧠
Sentence-Transformers para RAG semântico real
Substituir o embedding SHA-256 por sentence-transformers/all-MiniLM-L6-v2 (6MB, roda local). Habilita busca semântica real — perguntas sinônimas encontram os mesmos documentos.
sentence-transformers · ChromaDB
🤖
ViT real com timm (PyTorch)
Usar timm.create_model("vit_tiny_patch16_224", pretrained=False, num_classes=10) com fine-tuning. Elimina o mock atual e entrega benchmark real contra os modelos sklearn.
timm · PyTorch · Transfer Learning
🔄
GitHub Actions CI/CD
Pipeline: pytest → coverage → lint (ruff) → mypy em cada PR. Badge de cobertura no README. Docker Compose no CI para testar integração com Postgres e MongoDB.
GitHub Actions · ruff · mypy
